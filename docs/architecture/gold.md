# Слой Gold

Gold состоит из двух частей:

- **core** — схема «звезда» из [olist_star_schema.md](../data_models/olist_star_schema.md);
- **marts** — агрегированные витрины для аналитики.

Запуск:

```powershell
.venv\Scripts\python -m src.transformations.olist.gold_core
.venv\Scripts\python -m src.transformations.olist.gold_marts
```

Код: [gold_core.py](../../src/transformations/olist/gold_core.py) (~30 с),
[gold_marts.py](../../src/transformations/olist/gold_marts.py) (~20 с).

### Проверки (при ошибке сборка падает)

Результат пишется в `data/gold/olist/core/_validation.json`:

- первичные ключи уникальны и не пусты во всех 9 таблицах;
- 17 внешних ключей: нет пустых значений и «висячих» ссылок;
- число строк совпадает с Silver;
- `sum(price)`, `sum(freight)`, `sum(payment_value)` совпадают между таблицами товаров и платежей и `fact_orders`;
- ровно один последний отзыв на каждый заказ с отзывом.

### Бизнес-правила

| Правило | Реализация |
|---|---|
| Валидный заказ | `is_valid_order` (статус не canceled и не unavailable) |
| Выручка | `sum(price)` валидных заказов; доставка отдельно |
| Средний чек | выручка / валидные заказы |
| Повторный покупатель | ≥ 2 разных момента покупки (`customer_purchase_seq`) |
| Срок доставки | только доставленные заказы с непротиворечивыми датами |
| Опоздание | `date(delivered) > estimated_delivery_date` |

### RFM

- Дата отсчёта: день после последней валидной покупки (2018-09-04).
- R — квинтиль давности (5 = самые недавние). M — квинтиль выручки (5 = самые крупные).
- F — число покупок, ограниченное сверху числом 5. Квинтили для F не используются: 97% покупателей купили один раз.

| Сегмент | Название | Правило | Покупателей |
|---|---|---|---:|
| champions | Чемпионы | F ≥ 2, R ≥ 4 | 1 173 |
| loyal | Лояльные | F ≥ 2, R = 3 | 551 |
| at_risk | Под угрозой ухода | F ≥ 2, R ≤ 2 | 914 |
| new_high_value | Новые крупные | F = 1, R ≥ 4, M ≥ 4 | 14 773 |
| new | Новые | F = 1, R ≥ 4 | 22 050 |
| needs_attention | Требуют внимания | F = 1, R = 3 | 18 447 |
| hibernating_high_value | Спящие крупные | F = 1, R ≤ 2, M ≥ 4 | 14 079 |
| hibernating | Спящие | F = 1, R ≤ 2 | 23 003 |

## Сверка с независимым расчётом

Ключевые метрики пересчитаны в pandas напрямую по сырым CSV, в обход всего конвейера:

| Метрика | pandas по сырым данным | Gold |
|---|---:|---:|
| Выручка (валидные заказы, только товары) | 13 494 400,74 | 13 494 400,74 |
| Валидные заказы | 98 207 | 98 207 |
| Средний чек | 137,41 | 137,41 |
| Покупатели с валидными заказами | 94 990 | 94 990 |
| Доля повторных покупателей | 2,78% | 2,78% |
| Доля опозданий | 6,77% | 6,78% * |

\* Gold исключает 189 заказов с противоречивыми датами.

Если считать повторные покупки по заказам, а не по моментам покупки, доля получится 3,04%:
разбитые чекауты завышают её примерно на 9%.

8 валидных заказов не содержат товаров (статусы created, invoiced, shipped) и входят в средний чек с нулевой выручкой.
